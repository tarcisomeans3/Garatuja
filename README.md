** HTML **

significa Hyper text makup language.
O html é a linguagem de estruturazação do codigo.
Basicamente é ele que comanda tudo dentro do code,
Voce pode fazer paragrafos, colocar imagens, rodape, criar um formulario

** CSS **

Significa Cascading Style Sheets.
Ele que da a cara pro site, e estiliza ele.
com ele voce pode colocar cores, adicionar efeitos de transicao
e definir uma identidade visual para o codigo/site.
